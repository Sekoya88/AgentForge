# Security Policy

## Supported Versions

Currently, the `main` branch is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of AgentForge seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to us via email at **security@agentforge.dev** (placeholder) or send a private vulnerability report via GitHub.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you report a vulnerability that affects the platform or the sandbox execution environment, we will patch it as soon as possible and disclose the details when safe to do so.
